Ore Unifying project designed to reduce instances of ores to just 1

key features include
- finding all ores, dusts, ingots, nuggets and gems to place in a comprehensive JSON config file
- limiting the world generation to only include one of each ore dictionary entry
- limiting recipes to only input or output what is in the config file
- adjustable spawn configuration for default world generation

upcoming features
- loot table integration
- structure integration
- villager trading integration
